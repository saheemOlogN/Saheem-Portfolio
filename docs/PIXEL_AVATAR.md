# Pixel avatar

Generated using the built-in image generation tool. Asset: `public/art/character/saheem-pixel-three-modes.png`.

Four columns by three rows: idle looking around / Gear 5 / six-seven palms gesture. CSS animates the original transparent atlas without cropping or modifying the image. Navigation, game preview, and contact use the same component and artwork. System reduced-motion preferences retain a static frame.

## Generation prompt

Create a production pixel-art animation sprite sheet on a truly transparent background. Image 1 is the STYLE and CAMERA ANGLE reference: simple chunky square pixels, flat warm colors, cheerful head-only portrait facing forward, almost front-on with very slight turn, blocky outlines, retro game sprite. Image 2 is the IDENTITY reference only: preserve Saheem's black wavy hair, white rectangular eyeglasses, warm brown skin, small moustache and goatee. Restyle this identity to Image 1's very simple low-resolution pixel art, not detailed painted artwork.
EXACT layout: 4 columns x 3 rows of equal SQUARE cells, entire canvas 4:3 aspect ratio. All 12 sprites same center and scale, ample transparent padding, no grid lines, no labels, no text, no backgrounds. Each head occupies about 65% cell width and height so hair/hands/clouds never cross a cell boundary.
Row 1 four idle animation frames: face looking left, face looking ahead smiling, face looking right, eyes closed blinking. Small clear gaze/head changes with same silhouette.
Row 2 four Gear 5 animation frames: same recognizable glasses moustache goatee face with fluffy white cloud-shaped hair, big joyful grin, small white cloud wisps around head in changing positions creating a loop. Preserve face skin tone and glasses. Subtle head bob.
Row 3 four six-seven animation frames: same normal black-haired face, BOTH hands visible below and to either side with open palms facing up, alternately lifting left and right hands as the six-seven meme balancing gesture. Frame 1 left palm higher right lower, frame 2 both midway, frame 3 right palm higher left lower, frame 4 both midway. No hand signs, no written numbers. Keep whole hands inside each cell. Use crisp square pixel edges and simple readable features suitable for display at 80px.
